# 📚 Online Book Store SQL Data Analysis

> **A PostgreSQL SQL project analyzing books, customers, orders, sales, and inventory to derive meaningful business insights.**

---

## 📌 Project Overview

This project performs **SQL-based data analysis for an Online Book Store** using PostgreSQL.

The database consists of three main tables:

- 📚 **Books** — Book details, genres, prices, publication years, and stock
- 👥 **Customers** — Customer information and locations
- 🛒 **Orders** — Customer orders, quantities, order dates, and total amounts

The project demonstrates how SQL can be used to explore data, analyze sales, understand customer behavior, and monitor book inventory.

---

The `Orders` table is connected to both `Customers` and `Books` using foreign keys.

# 🔍 Analysis Performed

## 🟢 Basic SQL Analysis

The project starts with fundamental SQL queries to explore the bookstore data.

### 📚 Book Analysis

- Retrieve books from the **Fiction** genre
- Find books published after **1950**
- Calculate the **total stock** available
- Find the **most expensive book**
- Find the book with the **lowest stock**
- Identify all available book genres
- Retrieve the **top 3 most expensive Fantasy books**

### 👥 Customer Analysis

- Find customers from **Canada**
- Identify customers who placed **multiple orders**
- Find the customer who spent the **most**

### 🛒 Order & Sales Analysis

- Retrieve orders placed in **November 2023**
- Find orders with quantity greater than 1
- Find orders with total amount greater than **$20**
- Calculate **total revenue**
- Identify the **most frequently ordered book**

These exploratory queries are included in the SQL file as the first 11 analysis questions.

# 🚀 Advanced SQL Analysis

The project also includes more advanced business-oriented SQL questions.

### 1️⃣ Genre-wise Book Analysis

Analyzes book information by genre using aggregation and `GROUP BY`.

### 2️⃣ Average Book Price

Calculates the average book price by genre using:

```sql
AVG()
ROUND()
GROUP BY
```

### 3️⃣ Customers with Multiple Orders

Identifies customers who have placed **at least 2 orders** using:

```sql
JOIN
GROUP BY
HAVING
COUNT()
```

### 4️⃣ Most Frequently Ordered Book

Identifies the book ordered most frequently by joining the `Orders` and `Books` tables.

### 5️⃣ Top 3 Fantasy Books

Finds the three most expensive books belonging to the **Fantasy** genre.

### 6️⃣ Author-wise Sales Quantity

Calculates the total quantity of books sold by each author.

### 7️⃣ High-Spending Customer Locations

Identifies cities associated with customers whose orders have a total amount greater than **$30**.

### 8️⃣ Highest-Spending Customer

Finds the customer who has spent the most across their orders.

### 9️⃣ Remaining Book Stock

Calculates remaining stock after fulfilling ordered quantities using:

```sql
LEFT JOIN
SUM()
COALESCE()
GROUP BY
```

The advanced analysis section contains these nine business-oriented queries.
